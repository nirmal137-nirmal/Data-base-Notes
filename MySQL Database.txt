DBMS : Data base management System is a software to manage create and manipulate the data.

RDBMS : Relational Database Management System is a database to store a data in a Tabular form.

Type of RDBMS: MySQL, Oracle,  PostgreSQL, SQL Lite.

SQL : Structure Query Language its a Standard language for accessing and manipulating database.

MYSQL Structure : DDL, DML, DCL, TCL

DDL : Data Definition Language :- Create, Alter, DROP, TRUNCATE

DML : INSERT, UPDATE, DELETE, SELECT

DCL : GRANT, REVOKE

TCL : COMMIT, ROLLBACK
